# BIMVORA — ICP Profiles & Emotional Positioning

## 1. Primary ICP Profiles

### Profile A — The BIM Modeler / Revit Specialist
| | |
|---|---|
| **Title** | BIM Modeler, BIM Coordinator, BIM Engineer |
| **Company** | Engineering office (5–100 people), MEP consultancy, large contractor |
| **Experience** | 2–8 years in Revit |
| **Location** | Middle East, North Africa, Europe, Southeast Asia |
| **Day job** | Modeling MEP systems in Revit. Coordinating with structural and architectural models. |
| **Income** | Intermediate–senior professional |
| **Budget authority** | Can expense tools under ~$200 without approval; needs approval for more |

**Pain points (in their own words):**
- "I spend hours building the same FCU family every project. It's the same geometry, just different sizes."
- "The free families online have no connectors. They're useless for MEP coordination."
- "My client wants a Navisworks clash report this week. I can't waste time on families."
- "I downloaded 15 'free' families. None of them had the right Revit version. Three crashed my model."
- "My BIM standards require shared parameters, but every family I download has different parameter names."

**What they want:**
- Ready-to-load `.rfa` files that work — first time, every time.
- Correct connectors (duct, pipe, electrical) for clash detection.
- Shared parameters compatible with schedules.
- Revit 2022–2026 compatibility clearly stated.
- LOD 300/400 documented.
- Saves them 2–4 hours per family they don't have to model.

**Emotional triggers:**
- **Relief**: "I don't have to model this from scratch."
- **Pride**: "My model is clean and professional — not hacked together."
- **Speed**: "I submitted the coordination model an hour ahead of schedule."
- **Safety**: "These families won't crash my 800 MB model."
